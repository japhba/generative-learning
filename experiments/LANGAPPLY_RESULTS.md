# LANG-APPLY results (7 October 2026): recognition held fixed

Protocol: `LANGAPPLY_PROTOCOL.md`. Data: `results/task_search/lang_apply`, `lang_main` (set A, 29 episodes),
`lang_main2` (set B, 24 of 40 fresh episodes usable). Figure: `reports/lang-apply.png`.

Contrast C = same-language peer − other language on the double-centred reader × source accuracy matrix (reader skill
and general source quality removed); 95% episode bootstrap CI and two-sided sign-flip p.

| | N = 1 | N = 2 | N = 4 |
|---|---|---|---|
| Standard (LANG design), sets A + B | +2.6 [+0.6, +4.5] | +4.9 [+2.9, +6.8] | +1.9 [+0.2, +3.5] |
| Standard, fresh set B only | +0.9 [−1.5, +3.3] (pre-registered replication) | +4.3 [+0.8, +7.8] | −0.7 [−3.4, +1.9] |
| **Correct rule injected** | +1.7 [−0.7, +4.0] | +0.0 [−1.7, +1.8] | +0.9 [−0.9, +2.7] |
| Reader's own stated rule inserted | +0.8 | +0.9 | +0.3 |
| … only cells where that stated rule was correct | +3.2 [+0.8, +5.6] | +1.9 [+0.0, +3.9] | +2.1 [+0.6, +3.5] |
| Recognition (probe correct), set B | +16.0 | +11.3 | +12.2 |

- **Primary:** C under rule injection, averaged over N, is **+0.9 pp [−0.4, +2.1], p = 0.18** (n = 53). Set A gives
  +0.9 and set B +0.8.
- No ceiling: accuracy with the injected rule is 66–93% per reader.
- The demonstrations add +9 to +21 pp over the rule alone, about equally for own, same-language and other-language
  sources.
- Own − same-language peer under injection: −3.7, −2.0 and −3.5 pp. Own demonstrations stay less useful than a
  same-language peer's even when the rule is known.

**Reading.**

- The robust language effect is in **recognition**: readers extract the rule less often from other-language
  solutions, by 11–16 pp, replicated in both sets.
- The effect on **test accuracy** is smaller and less stable than LANG suggested. It holds pooled, but on the fresh
  episodes only at N = 2.
- Once the rule is known (injected), other-language demonstrations are applied as well as same-language ones (upper CI
  bound about +2 pp). The data therefore favour "understood less, hence applied less" over "recognised but applied
  worse".
- The small residual among self-stated correct rules (+2–3 pp) is a conditional, selected comparison. The clean
  manipulation (injection) does not support it.
