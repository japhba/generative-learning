Generative learning · model specification

The practice-loop toy model

A learner that has seen only single steps of a hidden 12-state ring practises multi-step routes, using its own frozen transition table to check them. This page defines every array, objective and update of the main experiment, and runs the model live in your browser on the 32 saved worlds.

1 · Task

States \(\mathcal S=\{0,\dots,11\}\) are bare integer ids. They lie on a hidden ring in a random order \(\rho\) (a permutation drawn per world), and the two actions step around it:

\[T_+(\rho_i)=\rho_{i+1},\qquad T_-(\rho_i)=\rho_{i-1},\]

with indices taken mod 12.

A task is a query \((s,g)\): reach goal \(g\) from start \(s\) within \(H=6\) actions. The query set excludes the start and its two (learned) neighbours,

\[\begin{gathered}Q=\{(s,g):\ s\neq g,\ g\notin\{\hat T_+(s),\hat T_-(s)\}\},\\ |Q|=108,\end{gathered}\]

so every goal is 2 to 6 steps away. Queries are drawn uniformly from \(Q\). No multi-step route is ever shown to the learner.

2 · Data and the checker (recognition model)

For each of the 24 pairs \((s,a)\) the learner observes \(K=5\) next states. Each is correct with probability \(1-\varepsilon\) and otherwise replaced by a uniform draw (\(\varepsilon=0.05\)):

\[\begin{gathered}s'_k\sim(1-\varepsilon)\,\delta_{T_a(s)}+\varepsilon\,\mathrm{Unif}(\mathcal S),\\ N[s,a,s']=\#\{k:\ s'_k=s'\}.\end{gathered}\]

That is 120 observations in total. The checker keeps the most frequent next state (ties go to the smallest id) and is frozen from then on:

\[\hat T_a(s)=\arg\max_{s'}N[s,a,s'].\]

The checker does two jobs during practice. It simulates each step, \(s_{t+1}=\hat T_{a_t}(s_t)\), and it judges each route,

\[r(\tau)=\mathbb 1\big[\exists\,t\le H:\ s_t=g\big],\]

with the rollout stopping at the first arrival. In all 32 saved worlds \(\hat T=T\).

3 · Generator (generation model): the only part that learns

Parameters are one angle per state, \(\theta\in\mathbb R^{12}\), giving unit embeddings and an embedding matrix

\[\begin{gathered}\mathbf u_s=(\cos\theta_s,\ \sin\theta_s)^\top,\\ \mathbf U=[\mathbf u_0,\dots,\mathbf u_{11}]\in\mathbb R^{2\times 12}.\end{gathered}\]

In state \(s\) with goal \(g\) the generator steps \(+\) with probability

\[\begin{aligned}p_\theta(+\mid s,g)&=\sigma\big(\beta\,\mathbf u_s^\top\mathbf J\,\mathbf u_g\big)\\ &=\sigma\big(\beta\sin(\theta_g-\theta_s)\big),\\ \mathbf J&=\begin{pmatrix}0&1\\-1&0\end{pmatrix},\quad \beta=6,\end{aligned}\]

and \(-\) otherwise. In words: a shared embedding layer followed by a fixed bilinear comparison. It steps \(+\) when the goal lies anticlockwise (within 180°) of the current state on its circle. The gain \(\beta\) and unit norms are fixed, so 12 numbers are all that is learned.

The action labels \(+/-\) carry no geometry for the learner: \(+\) is code index 0 of the transition arrays, and \(p_\theta\) is the probability of that index.

4 · Two learning rules for the same 12 angles

Ordinary training: reconstruct the observed steps

Predict which action produced each (cleaned) observed step, with labels \(y_+=1,\ y_-=0\):

\[\begin{gathered}L(\theta)=\frac1{24}\sum_{s,a}\Big[\log\big(1+e^{z_{s,a}}\big)-y_a z_{s,a}\Big],\\ z_{s,a}=\beta\sin\big(\theta_{\hat T_a(s)}-\theta_s\big).\end{gathered}\]

Gradient descent is local to the two endpoints of each step. With \(\delta_{s,a}=\tfrac1{24}\big(y_a-\sigma(z_{s,a})\big)\beta\cos\big(\theta_{\hat T_a(s)}-\theta_s\big)\):

\[\theta_{\hat T_a(s)}\mathrel{+}=\eta\,\delta_{s,a},\qquad \theta_s\mathrel{-}=\eta\,\delta_{s,a}.\]

Global minimum: neighbours 90° apart, \(\theta_{\rho_i}=i\pi/2\), with \(L=\log(1+e^{-6})={{optimum}}\). States 4 apart then coincide, and route success is {{folded}}. A once-round circle (30° per step) reaches {{ideal}} but has higher \(L\).

Practice: generate, check, reinforce

Objective: route success as predicted by the frozen checker,

\[J(\theta)=\mathbb E_{(s,g)\sim\mathrm{Unif}(Q)}\ \mathbb E_{\tau\sim p_\theta,\hat T}\big[r(\tau)\big].\]

Each update draws 32 queries (with replacement) and rolls each out twice, giving \(B=64\) routes. For route \(j\) with partner \(j'\) (same query), every step taken before arrival leaves a trace

\[e_{j,t}=\beta\,(a_{j,t}-p_{j,t})\cos\big(\theta_g-\theta_{s_{j,t}}\big),\]

where \(a=1\) for \(+\) and \(0\) for \(-\),

and with \(c_j=(r_j-r_{j'})/B\) the update is

\[\begin{gathered}\theta_g\mathrel{+}=\eta\sum_j c_j\sum_t e_{j,t},\\ \theta_{s_{j,t}}\mathrel{-}=\eta\,c_j\,e_{j,t}.\end{gathered}\]

\(e_{j,t}=\partial_{\theta_g}\log p=-\partial_{\theta_{s_t}}\log p\), and \(r_{j'}\) is independent of route \(j\), so \(\mathbb E[\Delta\theta]=\eta\nabla_\theta J\): REINFORCE with the partner as baseline. Three factors: activity at \(s_t\) and \(g\), the action fluctuation \(a-p\), and a scalar verdict. Nothing is back-propagated through \(\hat T\).

Settings

\(\eta=0.1\) for both rules, 3,000 updates, \(\beta=6\), \(H=6\), \(B=64\).

Control: no verdict

\(c_j=1/B\) for every route: all sampled actions are reinforced, whatever the outcome (\(\mathbb E[\Delta\theta]=0\)).

Control: shuffled verdicts

The 64 rewards \(r_j\) are randomly permuted across routes before \(c_j\) is formed.

5 · One practice pair, step by step

Uses the selected world and the sandbox's current practice angles (section 7). Each row is one action: the generator samples \(a_t\) from \(p_t=p_\theta(+\mid s_t,g)\), and the checker supplies \(s_{t+1}\).

6 · Evaluation

Success is computed exactly rather than sampled. With \(p=p_\theta(+\mid s,g)\), a backward recursion over the remaining horizon gives the probability of arriving:

\[\begin{aligned}V_0(s,g)&=\mathbb 1[s=g],\qquad V_h(g,g)=1,\\ V_h(s,g)&=p\,V_{h-1}\big(T_+(s),g\big)\\ &\quad+(1-p)\,V_{h-1}\big(T_-(s),g\big)\quad(s\neq g),\end{aligned}\]
\[\text{success}(\theta)=\frac1{|Q|}\sum_{(s,g)\in Q}V_H(s,g).\]

With the true \(T\) this is the true success that is reported; with \(\hat T\) it is the checker-predicted \(J(\theta)\). The two coincide in all 32 worlds because every \(\hat T\) is correct. Each \(V_h\) is a \(12\times12\) array, so evaluation costs \(6\times144\) operations.

Recorded every 20 updates: true success, \(J\), and \(L\). Runs are independent per world: 32 worlds, seeds 86200–86231, after an 8-world pilot. Across the 32 saved practice runs, mean final true success is {{savedMean}}.

In the code every array carries a leading world axis of length 32, and all 32 worlds are updated in parallel.

Starting points

Folded: \(\theta_{\hat\rho_i}=i\pi/2\), the exact global minimum of \(L\) (main experiment). Ordinary start: \(\theta\sim\mathrm{Unif}[0,2\pi)^{12}\), then 5,000 full-batch steps on \(L\) at \(\eta=1\) (control). Once round: \(\theta_{\rho_i}=2\pi i/12\) (reference only).

Data generation

Per world, np.random.default_rng(seed): \(\rho\) = permutation(12); then for each \((s,a)\), 5 observations, each corrupted with probability 0.05 to integers(12).
