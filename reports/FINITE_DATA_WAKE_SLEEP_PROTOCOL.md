# Finite real data and actual self-generated practice

This study returns to held-out loss versus real sample count and compute. Latent-state count, architecture, and the true task distribution stay fixed within each cohort. It is separate from the earlier million-state population study.

## Information available to the learner

Four independent binary causes generate eight observed binary variables through one sigmoid belief-network layer. The task is to predict the last two observed variables from the first six. The truth has 32 generative weights and eight biases; its weights are generated once and never exposed to training. The learner uses the same generative family and an affine 16-way softmax recognizer with 112 parameters. No latent labels are supplied in real examples.

N means N independent real observations, including naturally repeated values in the finite observation space. Datasets are nested prefixes of the same draw stream within each seed. Seven eighths are used for fitting and one eighth for validation, with a deterministic interleaved split. No fresh real observations enter an ongoing run. Validation examples count in N. Population evaluation enumerates the true observation distribution, exclusively in the evaluator; it is not training data or a stopping signal.

The generator is first fitted from the training portion of this same dataset by exact marginal MAP optimization, with a standard Gaussian parameter prior. It starts from random weights independent of the truth. Multiple initializations receive an equal budget; the smallest training MAP objective selects the common generator. Its compute is charged once to every arm. The generator is then frozen to isolate transfer from a learned forward model to an inverse model. Both arms therefore have the same finite information and the exact same imperfect generator. This is a first mechanism test, not jointly adapting the two directions.

## Learning rules and controls

- Wake: minimize reverse posterior KL on minibatches replayed from the finite real training contexts.
- Wake + sleep: the same wake step plus actual cause–context pairs drawn ancestrally from the learned generator. Every dream is retained; there is no checker, selection, or temperature adjustment. The cause is known because the model chose it when generating the context.
- Forward posterior teaching: inclusive posterior KL on the same real contexts, using the exact learned-model posterior. This diagnoses whether an objective change without imagined contexts explains a benefit.
- Direct prediction: train the recognizer to improve the likelihood of observed target variables in the same real data, backpropagating through the frozen generator's conditional output distribution. This provides a task-directed control that can compensate for generator error.

The recognizer starts with small, data-independent random weights and zero biases. No artificial neglected-state initialization is imposed. Independent random-number streams for real minibatches and dreams preserve paired real-example order between arms at equal update count.

## Axes, budgets, and evaluations

Primary loss is excess held-out conditional negative log likelihood, exactly KL(p_true(target | context) || prediction), averaged over true contexts. This measures observable prediction, avoids arbitrary latent-state alignment, and has a known zero Bayes-excess floor. Also record ordinary NLL, exact expected classification accuracy, learned-model posterior KL, and centered coefficient overlap with the posterior compiled from the learned generator. The compiled predictor is an informative reference, not a guaranteed lower bound on task loss under an imperfect generator.

Plot loss against N at prespecified equal recognition-compute allocations. Also plot loss against recognition compute at fixed N. Report shared generator fitting cost and total training cost explicitly. The approximate compute model counts leading dense multiply/add operations, includes ancestral dream generation, and excludes elementwise operations, data indexing, setup, and evaluation. Learned posterior tables are cached equally for all methods; neither method has access to true posterior tables. Matching the same shared fitting stage and the same subsequent compute budget matches total training compute within a given N and seed. Across N, fitting cost can differ because the common generator has a prespecified stationarity rule, so the data sweep fixes subsequent recognition compute rather than asserting constant total compute across N.

Regular evaluations are retained throughout training. Stop when both training loss and finite-data validation loss become stationary, using prespecified double-log slope thresholds. The true test loss is logged but cannot select stopping times. At a larger allocated budget, stopped models are held fixed and marked as stopped; their carried-forward values are not used as evidence for an error-versus-compute exponent. Nonfinite or exploding trajectories fail loudly. Each recognizer evaluation saves weights, Adam moments, counters, both RNG states, and stream position. Checkpoints are written to configured fast local storage before copying to persistent results. --resume restores all state and verifies the archived source and protocol; completed independent runs can also be reused.

Hyperparameters are selected in an exploratory cohort with a different fixed true distribution and independent dataset seeds, then frozen for confirmation. Each arm receives the same learning-rate grid. Selection uses mean log test prediction KL on that separate tuning world over the prespecified data sizes and compute budgets. No confirmatory exponent is promised. A lower loss at fixed data and compute is already relevant; a power fit is descriptive unless stable across windows and beyond optimization transitions. Any inference from the population toy to finite-sample results must be checked rather than assumed.

## Targeted approximation follow-up

The initial fully expressive comparison did not show a sleep benefit. We then changed only the recognition family for a follow-up: a standard mean-field distribution q(h | c) proportional to exp(h^T (R^T c + b)), with four independent conditional bits and 28 parameters. Unlike the 112-parameter categorical recognizer, this cannot encode posterior interactions among latent causes. The generative family, real-data protocol, no-filtering rule, and evaluation task are unchanged. Each arm uses the same restricted family within this comparison.

The follow-up selects rates on the original tuning world 9820 and dataset seeds 9821–9822, then evaluates a new fixed world 9850 with fresh dataset seeds 9851–9862. The original fully expressive confirmation world was 9830, with dataset seeds 9831–9842. This initial comparison spans two separately fixed worlds; the subsequent capacity check below pairs the same world. Both main cohorts use N in {16,32,64,128,256,512,1024,2048,4096,8192}. The same six recognition rates {0.001,0.003,0.01,0.03,0.1,0.3} are considered per arm on the tuning world. Adam's rate is divided by sqrt(1 + charged_wake_equivalents / 128). The three primary recognition allocations are 256, 1024 and 4096 ordinary wake-update equivalents.

A subsequent compute diagnostic replays the frozen factorized configuration at N=512, 2048 and 8192 to 512 wake equivalents, across all 12 seeds and three arms. This checks executed work before stationarity can save compute. Wake and posterior teaching execute 512 updates; sleep executes 239 combined updates with 15,296 dreams and 510.59 wake-equivalent matrix-product FLOPs. This diagnostic uses the existing confirmation datasets and frozen rates; it is not an independent confirmatory sample. No further task or learning-rate search was conducted after seeing the follow-up confirmation.

Fit windows are {32–8192,128–2048,512–8192} for the fully expressive experiment. We do not identify the restricted-family curves with new asymptotic data exponents: approximation errors can produce distinct nonzero floors. The stronger forward-posterior control is necessary to distinguish useful generative supervision from a claim that novel imagined contexts are indispensable.

The final paired capacity check trains fully expressive recognition on the exact same world, observed datasets and fitted generator checkpoints as the factorized replay, at N=512, 2048 and 8192. It uses the full-family rates already selected on the separate tuning world. The budget is 469 full-family wake equivalents, aligning the larger per-update cost with 512 factorized wake equivalents. All four family/method executed dense budgets are within 0.4%. The 72 runs do not select new hyperparameters. This directly checks whether the earlier cross-world comparison was misleading.
