A model can help itself when its samples receive feedback

Research batch b2k · 07 September 2026, 13:58 BST · Completed experiment

At 512 training rollouts, current-source accuracy is 34.64%, versus 23.44% for the frozen source, on 128 untouched questions. The advantage is +11.20 pp, with hierarchical 95% interval [+7.42, +14.94] pp. The exact selection identity and initial weight-gradient overlaps provide a predictive connection to a conditional Boltzmann toy. A one-scalar model explains part of the behavior, but does not accurately predict the entire LLM curve.

The specific LLM claim tested is that refreshing the model that generates selected training traces improves learning over continuing to sample from its initial weights. Both conditions generate data and receive the same correctness feedback. This LLM contrast does not establish a benefit from unfiltered self-generation, or an advantage over every recognition or supervised-learning procedure. A separate no-feedback toy extension is reported below.

What was trained

The model is Qwen/Qwen2.5-1.5B-Instruct, revision 989aa7980e4cf806f80c7fef2b1adb7bc71aa306. All approximately 1.54 billion weights are trained in FP32, with TF32 disabled. Plain SGD uses rate 0.00012132033309492577, without adapters, clipping, decay or an adaptive optimizer. Summed completion-token negative log likelihood is divided by a fixed 128 and averaged over 16 selected responses.

Each seed supplies 64 training arithmetic programs and a separate 96-question recurring evaluation set. A program starts with a number and performs 12 additions, subtractions or multiplications with larger integers. The source generates two complete responses per training prompt at temperature 1. A deterministic simulator checks the final answer. A uniformly random maximum-correctness response supplies the training tokens. If both responses fail, a failed response is still selected. Equation formatting never selects examples.

The current source uses the learner’s latest weights. The frozen source generates fresh responses from the original weights throughout training. Prompts, candidate counts, tie schedules, update counts and feedback rules are matched. First candidate/target banks and losses are checked for exact equality within each pair. Test-time answers are sampled without best-of-N selection.

The exact probabilistic connection

For one prompt, let p be success probability and g(Y)=∇log π(Y) the full-trajectory score. With N independent draws and uniform maximum-reward ties, selected success is qN(p)=1−(1−p)N. Selection preserves the conditional distribution inside each reward class, giving:

E[g(selected)] = c_N(p) ∇p
c_N(p) = 1 + (1−p) + ... + (1−p)^(N−2)
N = 1: expected update is zero
N = 2: expected update is exactly ∇p

Across prompts, initial held-out gains depend on Kij=⟨∇pi,∇pj⟩. Positive weight-gradient overlaps transfer gains between questions. At equal candidate count the local per-prompt factor is cN(p)/N. N=4 versus N=2 reverses ordering at p≈0.382 in a homogeneous reduction; the actual LLM forecasts use measured overlaps for heterogeneous prompts.

An RBM with eight interpretable weights

E_w(x,y) = ||x||²/2 − y w·x,    y ∈ {−1,+1}
Z(w) = 2 (2π)^(d/2) exp(||w||²/2)
p_w(y|x) = exp(y w·x) / [2 cosh(w·x)]
x = y_true μ + Gaussian noise
ρ = (w·μ) / (||w|| ||μ||)

This Gaussian-visible, binary-hidden Boltzmann model has one weight vector. The same selected-output rule trains its conditional policy. Population drift dw/dt=Aμ+Bw gives dρ/dt=||μ||(1−ρ²)A/||w|| with A>0 for N>1. Selection rotates weights toward the useful direction. A frozen proposal has a fixed selected-target sufficient statistic.

For initial overlap 0.3 and N=2, current-source error reaches 6.71%, versus 22.66% frozen. The difference is −15.95 percentage points, 95% interval [−16.07, −15.84]. This uses 256 replicas, 1,024 updates, batch 32 and rate 0.05. Six cases include N=1 and negative initial overlap. N=1 does not show comparable learning.

Sampled toy accuracy is 91.88% current versus 73.40% frozen, a difference of +18.48 pp. This metric depends on both weight norm and overlap, while the preceding greedy classification error depends only on overlap.

Binary feedback reveals the label in this toy, so its information complexity differs from checking long reasoning. Conditional reward learning also need not improve marginal density. This is not contrastive-divergence training: CD contrasts data-anchored and model statistics, whereas these updates fit reward-selected conditional samples. See Hinton’s contrastive-divergence paper.

Predictions made before LLM updates

Before each four-update block, an independent rollout bank estimates the selected-training gradient. Its overlap with a held-out success gradient predicts the block’s gain. The forecast is saved before drawing training samples. Diagnostic tokens and gradients never enter the optimizer or choose the learning rate during these runs.

Finite-sample selection diagnostic

An N=1 bank has a nonzero realized score despite zero expectation. Its ordinary-score component contributes 1/N of the N=1 update to the N contrast at matched candidates. After inspecting the importance results, we declared this first-order diagnostic before the larger fresh check:

selection diagnostic = (p_N − p_0) − (p_1 − p_0)/N

This local decomposition is not a different trained model. Total gains remain the performance endpoint.

Can one Boltzmann gate explain the curve?

In the discovery seed, responses containing an equals sign rise from 58.6% to 91.7%, while their conditional correctness stays near 33%. Much of the gain may therefore come from using an existing strategy more often. An equals sign identifies an output mode, not valid reasoning.

H ~ Bernoulli(λ),   λ = sigmoid(z)
Y | H ~ Q_H          (two fixed normalized distributions)
success = b + (a−b) λ
z_next = z + k [mean selected H − λ_train(z)]

This normalized Boltzmann factor has one learned scalar. Current-source best-of-2 keeps increasing the gate when a>b; a frozen source approaches its initial selected-mode frequency. Training and evaluation have distinct initial offsets and a shared logit displacement. k=1.3892 is calibrated from the discovery initialization’s pre-update gradient forecast, without fitting its later curve.

A separate positive no-feedback toy result

While the last LLM confirmation ran, we tested one explicit inductive bias in the earlier no-feedback toy: project the weights back to their initial unit norm after every self-sampled score update. Sampling and fitting temperatures remain 1, no outputs are filtered, and no correctness feedback enters training. The input examples still come from the real Gaussian mixture.

From initial overlap 0.3, marginal cross-entropy improves by 0.1141 nats per input, 95% interval [−0.1164, −0.1117]. The improvement exceeds isotropic noise by 0.0830 nats. Classification still worsens, from 32.64% error to 46.45%; sign reversals preserve mixture density but break label orientation. This is a probabilistic representation benefit, not a better classifier.

The initial analytic density-change coefficient is −0.6475 for self-sampled noise, versus −0.1100 for isotropic noise. An independent finite-difference audit agrees within Monte Carlo uncertainty. Normalization prevents the norm growth that spoiled density fit in the unconstrained study, and introduces a second-order weight drift. Thus zero expected score before projection does not imply zero change afterward.

This extension was discovered after the unconstrained failure and then confirmed with fresh seeds. It changes the algorithm through a norm constraint. It is not evidence that an isolated model creates information: real inputs provide the structure, and covariance-matched Gaussian noise reproduces the gain. No corresponding no-feedback LLM benefit has been demonstrated.

Scope and failed checks

The supported setting combines a conditional probabilistic learner, full-trace likelihood training, explicit success selection and a current-versus-frozen proposal contrast. The toy has exact overlap dynamics; local LLM overlaps predict part of learning. A single scalar does not yet predict the whole LLM trajectory.

No scaling exponent is measured. The gate’s continuous-time model can have 1/t decay of excess error near its attainable ceiling, while a frozen target approaches a different limit. This is a toy asymptotic. One architecture and arithmetic family cannot establish generality across ICL, humans or other models.

The first BF16 differential probe failed. FP32 restored small-step agreement; a separate generation-versus-scoring audit agreed within 0.001 nats on each tested trajectory. Accuracy may improve while likelihood of a canonical wording worsens. The earlier no-feedback finite-sample study recovered an unsigned axis but worsened classification and density fit; it did not establish useful learning without feedback.

Related algorithms include RAFT, which fits reward-ranked generations, and STaR, which bootstraps reasoning with correctness and answer-conditioned regeneration. No novelty claim is made for the basic algorithm or score identity.

Failures, sources, protocols, responses and checkpoint provenance are retained. Checkpoints include optimizer, scheduler, RNG and data position; resume reproduced the next update exactly.
