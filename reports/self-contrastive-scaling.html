Does refreshing generated negatives change the learning exponent?

Updated 2026-09-08T13:51:17.270401+01:00. Local CPU experiments; no paid API or rented compute.

Feature learning changes the exponent; refreshing generated negatives improves error at a finite budget. In the main Gaussian setting, shallow models approach exponent 0.50 and two-layer models approach 0.67. Both frozen and refreshed sources share the exponent within each architecture.

The comparison

Both arms learn the same normalized Gaussian conditional density by classifying real versus generated observations. Every update receives one real observation and one generated negative per input. Negative samples are labeled by their origin; no answer checker is used. All initial functions are zero and the two architectures have the same initial tangent kernel. Both source arms train the same parameters within an architecture.

Why the source has not changed the exponent

For Gaussian inputs, the frozen-source Fisher matrix can be written as Lambda^(1/2) [h_perp (I−uuᵀ) + h_parallel uuᵀ] Lambda^(1/2), where u is the unit whitened target direction. Both coefficients are strictly positive at finite signal variance. In the main case they bound the Fisher matrix between 0.2409 Lambda and 0.3798 Lambda. Refreshing gives 0.5 Lambda. The frozen source weakens learning, but its local geometry retains the same slow spectral order.

The two-layer learner instead develops a growing effective kernel through its factor weights. This mechanism is available under both source choices. The hypothesis of equal source exponents and the slope windows were recorded in protocol.json before the main runs.

Numerical verification and reproducibility

Doubling time-grid resolution, spectral quadrature, and Gaussian quadrature changes the main curves by at most 0.16%. The shallow current curve agrees with its exact modal solution within 0.04%. An independent explicit RK4 integration of the original factor weights agrees with the reduced deep solver within 0.09%. A finite-sample orthogonal-rotation update check passes to machine precision.

Scope

  • Late exponents are population-flow fits, not finite-sample exponent estimates.
  • Population spectrum is logarithmic quadrature down to lambda=1e-18, not 1024 ordinary equally weighted modes.
  • The finite SGD experiment uses actual 1024-dimensional Gaussian observations and power-law eigenvalues; its discrete spectrum differs from the population quadrature.
  • The common Gaussian likelihood has additive observation noise; excess NLL is computed analytically, avoiding test-set noise.
  • Six-seed bootstrap intervals cover training randomness in this model, not model-family uncertainty.
  • Both methods receive real observations and generated negatives; this is not pure self-imitation or a direct LLM experiment.

This experiment supports a coefficient benefit from adaptive self-generation in a canonical Gaussian family. It does not establish a generation-specific exponent advantage. Producing that would require an additional mechanism that changes the slow spectral order or its evolution.
