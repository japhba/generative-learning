A one-weight sleep toy with symmetric specificity

Input (m,c), m>0 and c∈{0,1}. Any z with |z|=m is correct. Source A returns m; source B returns (−1)cm. Both are 100% correct on the same inputs. Reader A has φ=m; reader B has φ=(−1)cm. Each predicts ẑ=wφ, starting at w=0.25.

Same loss: L = ½((wφ − z)/m)²
Same update: w ← w + η[(φ/m)(z/m) − w]
Own source: (φ/m)(z/m) = 1
Other source: (φ/m)(z/m) = ±1 with mean 0

Own examples drive w toward 1. Cross-source labels conflict in the restricted feature space and drive the mean toward 0. No source-specific bonus or correctness judgment appears in the update.

Both features [m,(−1)cm] let either reader fit either source. The original feature alignment is assumed, not learned. This is a sleep-phase recognition loss with fixed generators, not a complete wake–sleep model. Native error is (1−w₀)²(1−η)2N, checked against 4,096 simulations: exponential relaxation, not a power law.
